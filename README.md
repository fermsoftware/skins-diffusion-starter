
## 🚀 Skins Diffusion Starter

A ready-to-use starter template for [Skins Diffusion](https://pypi.org/project/skins-diffusion/).

> [!NOTE]
> This starter does not include game assets. You must provide your own extracted resources before running examples.

### ✨ Features

- **Practical examples** — Explore how to use Skins Diffusion in your own scripts.
- **Simple setup** — Install dependencies and start experimenting in minutes.

### 📋 Requirements

Before getting started, make sure you have the following:

- Python 3.9 or newer (https://www.python.org/)
- Required resource files extracted from a game client.

### 🛠️ Setup

Clone the Repository:

```bash
git clone https://github.com/fermsoftware/skins-diffusion-starter.git
cd skins-diffusion-starter
```

Create and activate a Python virtual environment:

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux/macOS
python3 -m venv venv
source venv/bin/activate
```

Install the [Skins Diffusion](https://pypi.org/project/skins-diffusion/) package from PyPI:

```bash
# Windows
pip install skins-diffusion

# Linux/macOS
pip3 install skins-diffusion
```

### 🌱 Prepare Your Resources

Skins Diffusion requires a specific directory structure for its resource files.

Follow the [resource preparation guide](https://github.com/fermsoftware/skins-diffusion-starter/tree/main/Resources) to learn how to organize the required files.

> [!IMPORTANT]
> Make sure your resources are placed in the expected directories before running examples that depend on them.

### 🔥 Run an Example

Once the installation and resource setup are complete, run an example:

```bash
# Windows
python examples/example_binaryx.py

# Linux/macOS
python3 examples/example_binaryx.py
```
